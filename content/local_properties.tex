\begin{definition}
    Let P be a property of ring $A$ that is preserved 
    under localization ($S^{-1}A$ has property P
    for all multiplicative set $S\subset A$.
    Then, each of the following is stronger than the next.
    \begin{alphenum}
    \item $A$ has property P.
    \item There exists $f_1,\dots,f_n\in A$ generating a unit ideal such that $A_{f_i}$ has property P for all $i$.
    \item $A_\pp$ has property P for all prime ideal 
    $\pp\subset A$.
    \end{alphenum}
    Then, we make the definition. Property P is
    \begin{itemize}
    \item \vocab{stalk-local}
    if (c) implies (a).
    \item \vocab{open cover local} if (b) implies (a).
    \item \vocab{spreading out} if for every prime ideal $\pp$ such that $A_\pp$ has property P,
    there exists $f\notin\pp$ such that $A_f$ has property P.
    (This is stronger than (c) implies (b).)
    \end{itemize}
\end{definition}
One can similarly define these three words for properties of 
$A$-modules, a pair of $A$-modules, etc.

\paragraph{Comments}
\begin{enumerate}
    \item The following statement is true:
    if $A$ is Noetherian, $\Spec A$ is connected,
    and $A_\pp$ is a domain for every prime ideal $\pp$,
    then $A$ is a domain.
    \label{list:domain}
    \item If we assume $M$ is finitely-presented,
    then this entry would be YES.
    \label{list:free}
\end{enumerate}
